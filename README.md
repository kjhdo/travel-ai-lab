# 여행 AI 실습 가이드 (숭의여대 12/12)

**ChatGPT 무료버전으로 여행 준비 & 나만의 여행 웹앱 만들기** — 숭의여대 부설 평생교육원 「도서관정보시스템론」 2026. 12. 12.(토) 실습용 인터랙티브 가이드입니다.

- **바로 보기**: https://kjhdo.github.io/travel-ai-lab/
- PC(실습실 모니터)와 모바일 모두에서 열립니다. 설치·로그인·결제 없음.

## 쓰는 법

1. 「내 조건 빠른 입력」에 목적지·날짜·인원·예산을 적으면 아래 모든 프롬프트의 `[대괄호]`가 실시간으로 바뀝니다. (비워 두면 예시 조건 그대로 복사됩니다.)
2. 각 프롬프트의 **복사** 버튼을 눌러 ChatGPT에 붙여넣습니다. Step 1~4는 **같은 대화**에서 이어서 진행합니다.
3. 단계를 끝낼 때마다 **완료 체크**를 누르면 상단 진행 바와 완료 단계 수가 채워집니다. 체크 상태와 입력한 조건은 브라우저(localStorage)에 저장되어, 창을 닫았다 열어도 그대로 남습니다.

## 구성

| 단계 | 내용 | 시간 |
|---|---|---|
| Step 0 | 시작 전 준비 & 무료버전 주의 3가지 | 5분 |
| Step 1 | 항공권 찾아 비교하기 (웹 검색) | 10분 |
| Step 2 | 시간대에 맞춰 일정표 만들기 | 10분 |
| Step 3 | 대화로 고치기 (① 비 오는 날 ② 걷기 최소화 ③ 예산 절감) | 8분 |
| Step 4 | 폰에서 열리는 여행 웹앱 만들기 (Preview → 복사 → `travel.html` 저장) | 20분 |
| Step 5 | 폰에서 열기 · 보너스 미션 3종 · 막혔을 때 FAQ | 7분 |
