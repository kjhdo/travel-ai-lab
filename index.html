시작 전 준비 & 무료버전 주의 3가지

약 5분 · 로그인만 하면 끝

시작 전 1분 — chatgpt.com에 무료 계정으로 로그인 → 새 대화 열기 → Step 1 프롬프트를 복사해 붙여넣기. 준비는 이게 전부입니다.

🔑
반드시 ChatGPT 무료 계정으로 로그인한 뒤 시작하세요로그인 없이 진행하면 4번째 질문 무렵 로그인 팝업이 뜨고, Step 4의 미리보기 버튼이 비활성화되어 눌리지 않습니다.

무료버전에서 꼭 지킬 3가지

  • 1대화창은 처음부터 끝까지 하나만Step 1~4는 모두 같은 대화에서 이어서 합니다. 새 대화를 열면 AI가 앞의 항공권·일정 내용을 잊습니다. 무료버전은 사용량 제한이 있으니 이 순서대로 네 번의 질문 안에 끝내세요.
  • 2웹앱은 "HTML 파일 1개"로 부탁인터넷에서 코드나 폰트·이미지를 빌려오는 방식(CDN 등)이 섞이면, 미리보기에서는 되는데 저장한 파일은 하얗게 나옵니다. Step 4 프롬프트에 이 조건이 이미 들어 있으니 그대로 쓰시면 됩니다.
  • 3항공권 가격은 링크로 교차 확인AI가 주는 가격은 조회 시점의 참고값이고 실제 예매가는 수시로 바뀝니다. 함께 받은 링크를 눌러 항공사·예매 사이트에서 확인하세요. 링크가 안 열리면 항공사명과 편명으로 직접 검색합니다.
1

항공권 찾아 비교하기

약 10분 · 웹 검색

아래를 그대로 복사해 붙여넣고, [대괄호] 안만 내 조건으로 바꾸세요. (예시는 서울→오사카)

프롬프트 1그대로 복사해서 붙여넣기
너는 여행 예약 도우미야. 아래 조건에 맞는 항공권을 웹 검색으로 찾아서 비교표로 정리해줘.

- 출발지: [서울(인천 or 김포)]
- 도착지: [오사카]
- 가는 날: [2027년 3월 6일(토)] / 오는 날: [2027년 3월 9일(화)]
- 인원: [성인 2명]
- 예산: 왕복 1인 [35만원] 이하
- 희망 시간대: 갈 때 [11시 이전 출발] / 올 때 [17시 이후 출발]
- 수하물: 위탁 [15kg] 포함 여부도 표시해줘

조건
1) 항공사, 편명, 출발·도착 시각, 소요시간, 왕복 총액, 수하물 포함 여부를 표로 3~5개만.
2) 예산을 넘는 편은 '참고'로 따로 표시.
3) 각 편을 실제로 예매할 수 있는 공식 사이트 링크를 함께 달아줘. 가격은 조회 시점 기준이라 바뀔 수 있다는 점도 알려줘.
4) 마지막에 '가장 저렴한 편'과 '시간이 편한 편'을 하나씩, 이유와 함께 추천해줘.
🔍확인 포인트 — 표에 링크가 붙었나요? 링크를 눌러 실제 가격·시간이 표와 맞는지 한 번만 대조해 보세요.
2

시간대에 맞춰 일정표 만들기

약 10분 · 같은 대화에 이어서

마음에 드는 항공편을 정했으면 같은 대화에 이어서 붙여넣습니다.

프롬프트 2같은 대화에 이어서
이제 위에서 추천한 [대한항공 KE721, 09:20 출발] 편을 타는 걸로 하고 [2박 3일] 일정표를 짜줘.

- 숙소: [난바역 근처 호텔]
- 동행: [친구 2명] / 하루 걷는 양: [8,000보 이내]
- 취향: [시장 먹거리, 조용한 카페, 미술관]
- 하루 세 끼 식당 후보를 각 2곳씩 (현지식 위주, 예약 필요 여부 표시)
- 이동수단(지하철/도보/택시)과 이동 시간, 예상 비용(현지 통화 + 원화)
- 표 형식: 시간 | 장소 | 할 일 | 이동 | 비용
- 첫날은 도착 후 짐 푸는 시간을 넣고, 마지막 날은 비행기 출발 2시간 30분 전 공항 도착으로.
🔍확인 포인트 — 첫날 도착 시간과 마지막 날 공항 도착 시간이 Step 1의 항공편과 맞는지 보세요. AI가 시간을 어긋나게 짜는 경우가 가장 흔합니다.
3

대화로 고치기

약 8분 · 한 번에 하나씩

일정표는 한 번에 완벽하지 않습니다. 한 번에 하나씩 부탁하는 것이 요령입니다. 아래 ①~③ 중 하나만 골라 복사해 붙여넣으세요.

프롬프트 3-①
3일차 오후에 비가 온대. 실내 위주로 바꿔줘. 바뀐 부분만 표로 보여줘.
프롬프트 3-②
걷는 시간이 너무 길어. 같은 동네 안에서 도는 코스로 줄이고, 이동은 지하철 위주로 다시 짜줘.
프롬프트 3-③
예산을 1인 [20만원] 줄여야 해. 식당은 한 끼 [1만 5천원] 이하로 바꿔줘.
💡요령 — "바뀐 부분만 보여줘"를 꼭 붙이세요. 그러지 않으면 일정표를 처음부터 다시 써서 앞의 좋은 부분까지 바뀝니다. 조건을 두 개 이상 한꺼번에 주면 AI가 하나를 빠뜨리기도 합니다.
4

폰에서 열리는 여행 웹앱 만들기

약 20분 · 오늘의 하이라이트

Step 2의 일정표를 앱으로 바꿉니다. 응답이 오래 걸리는 단계이니, 기다리는 동안 Step 5의 폰으로 옮기는 방법을 미리 읽어 두세요.

프롬프트 4그대로 복사
위 일정표를 여행 중에 폰으로 보면서 쓰는 웹앱으로 만들어줘. 아래를 꼭 지켜줘.

1) 외부 라이브러리 없이 HTML 파일 1개로. CSS와 JavaScript는 파일 안에 넣고, 인터넷이 없어도 열려야 해. CDN·외부 폰트·외부 이미지 금지, 아이콘은 이모지로.
2) 모바일 화면에 최적화(폭 360~430px). PC에서 열면 가운데 정렬.
3) 화면 구성: ① 1일차 / 2일차 / 3일차 탭  ② 시간·장소·할 일·비용 목록  ③ 항목마다 체크박스  ④ 맨 위에 여행 제목과 D-day(여행 첫날까지 남은 날짜 자동 계산)
4) 체크 상태와 메모는 localStorage에 저장해서, 폰을 닫았다 열어도 그대로 남게 해줘.
5) 준비물 체크리스트 탭도 추가 (여권, eSIM, 충전기, 상비약 등).
6) 글씨는 크게, 버튼은 손가락으로 누르기 쉽게. 색은 [하늘색] 계열.
7) 파일 이름은 travel.html. 전체 코드를 HTML 코드 블록 하나에 한 번에 다 보여줘. 코드를 나눠서 보내지 마.

미리보기와 파일 저장 (2026년 현재 한국어 화면 기준)

(영문 화면에서는 Preview / Copy code)

1미리보기코드 블록 오른쪽 위의 미리보기 버튼을 누르면 채팅 안에서 앱이 바로 실행됩니다. 무료 계정도 됩니다. 전체 화면 아이콘으로 크게 볼 수 있고, 코드를 직접 고치면 미리보기에 즉시 반영됩니다. 고친 뒤에는 최종 코드를 다시 코드 복사로 복사해 저장하세요.
2파일로 저장 — 코드 복사 → 메모장코드 블록의 코드 복사 → PC의 메모장에 붙여넣기 → 파일 → 다른 이름으로 저장 → 이름 travel.html, 형식 '모든 파일', 인코딩 'UTF-8' → 저장한 파일을 더블클릭하면 브라우저에서 열립니다.
3로그인하지 않아 미리보기가 흐려져 있다면미리보기 버튼이 비활성화(흐림) 상태라도 코드 복사 버튼은 정상 동작합니다. 그대로 복사해 메모장에 붙여넣고 travel.html로 저장한 뒤 브라우저에서 열어 확인하세요.
4참고ChatGPT의 캔버스(Canvas)는 2026년 5월에 종료되어, 지금은 코드 블록의 미리보기 + 코드 복사가 표준입니다. 코드 블록에는 '다운로드' 버튼이 없습니다.
⚠️미리보기 버튼이 안 보인다면 — 코드가 HTML로 인식되지 않은 것입니다. 한 번만 이렇게 부탁하세요. 아래 버튼으로 복사해 붙여넣으면 됩니다.
프롬프트 4-보조미리보기가 안 될 때만
HTML 코드 블록으로 다시 보여줘. 미리보기(Preview)가 되는 형태로.

내가 만든 웹앱, 폰에서 열기

약 7분 · 보너스 미션 · 막혔을 때
A
카톡 '나에게 보내기'
PC 카톡의 '나와의 채팅'에 travel.html 파일을 끌어다 보내고, 폰 카톡에서 그 파일을 엽니다. 간단하지만 아이폰은 미리보기가 안 열릴 수 있으니 B를 권합니다.
B
Netlify Drop 추천
app.netlify.com/drop 접속 → travel.html을 화면에 끌어다 놓기 → 나온 주소(https://….netlify.app)를 폰 브라우저에 입력 → 공유 → 홈 화면에 추가. 계정 없이 배포되며, 주소는 공개되니 실제 개인정보는 넣지 마세요.
C
구글 드라이브 / USB
travel.html을 구글 드라이브에 올려 폰의 드라이브 앱에서 열거나, USB로 옮겨 파일 관리자에서 엽니다(안드로이드는 Chrome에서 열립니다).

먼저 끝났다면 — 보너스 미션 3가지

같은 대화에 이어서 부탁하면 됩니다. 하나만 골라도, 셋 다 해도 좋습니다.

보너스 ① 환율 계산기 탭
상단에 '환율' 탭을 추가해줘. 100엔 = [930]원 기준으로 엔→원, 원→엔 양방향 계산이 되고, 환율은 화면에서 직접 고칠 수 있게.
보너스 ② 다크모드 토글
오른쪽 위에 해/달 모양 토글 버튼을 넣고 다크모드로 바꿀 수 있게 해줘. 다크모드 설정도 localStorage에 저장해줘.
보너스 ③ 현지 회화 카드
'회화' 탭을 추가해줘. 공항·식당·길찾기에서 쓸 [일본어] 표현 12개를 카드로 보여주고, 카드를 누르면 큰 글씨로. 발음은 한글 표기로.

여유가 있으면 '정산' 탭도 재미있습니다.

보너스 ＋ 정산 탭
지출 금액과 인원 수를 넣으면 1인당 얼마인지 계산해주는 '정산' 탭을 추가해줘.

막혔을 때 — 당황하지 말고 이 네 줄

증상이렇게 하세요
"무료 사용 한도에 도달했어요"잠시 기다리거나, 이미 받은 코드를 복사해 저장해 두고 옆 사람과 함께 진행하세요. 선생님께 알려 주세요.
코드가 중간에 잘려서 나와요"코드가 잘렸어. 잘린 부분부터 이어서 보여줘."
미리보기가 하얗게만 나와요"미리보기가 하얗게 나와. 오류 난 부분만 고쳐서 전체 코드를 다시 보여줘."
예매 링크가 안 열려요항공사 이름과 편명으로 직접 검색하세요. AI가 링크를 그럴듯하게 만들기도 합니다.
AI는 답을 주는 도구가 아니라, 조건을 주면 일을 해 주는 도우미입니다. '조건 주기 → 한 가지만 고쳐 달라 하기 → 결과물을 파일로 꺼내 쓰기'는 여행뿐 아니라 보고서, 안내문, 행사 준비에도 그대로 통합니다.
